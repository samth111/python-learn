# 🐍 Python 闯关练习（代码补全）

一个清新简洁的前端学习网站，通过「补全代码」的方式帮助你深度掌握 Python 基础语法。

## 功能特性

- **150 道代码补全题**，覆盖 **18 大章节**：变量与数据类型、运算符、字符串、列表、元组与集合、字典、条件判断、循环、函数、综合挑战、内置函数、推导式、lambda 与高阶函数、作用域、模块与导入、异常处理、文件操作、综合挑战 II。
- **难度梯度**：入门(26) → 基础(63) → 进阶(47) → 挑战(14)，可一键筛选。
- **每道题标注考察知识点**，并在答题后展示**知识点详解 + 参考答案**。
- **浏览器内真实运行 Python**（基于 [Pyodide](https://pyodide.org/)，WebAssembly 版 CPython），运行后即时显示 ✅ 正确 / ❌ 未通过，并给出程序输出。
- **本地进度保存**（localStorage），答对自动记录，可随时重置。
- **收藏夹**：点题目右上角 ☆ 收藏，侧边栏「收藏夹」一键只看收藏题目，便于集中复习。

## 如何运行

直接双击 `index.html` 即可在浏览器打开（首次点击「运行代码」会联网下载约 10MB 的 Python 环境，之后浏览器会缓存）。

也可以起一个本地静态服务器：

```bash
cd python-learn
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
python-learn/
├── index.html          # 页面结构
├── css/style.css       # 清新简洁的样式
└── js/
    ├── questions.js    # 150 道题目数据（代码模板 / 答案 / 测试 / 详解）
    └── app.js          # 界面逻辑 + Pyodide 运行与判分
```

## 判分原理

每道题都隐藏了一段 `test` 断言。点击运行后，你的代码会在浏览器里被真实执行，随后执行断言：

- 全部断言通过 → ✅ 回答正确，并记录进度；
- 断言失败 → ❌ 未通过，显示运行输出；
- 代码报错 → ⚠️ 运行出错，显示异常信息。

## 提示

- 编辑器里用 `___` 标记空白，运行前请把所有 `___` 补全。
- 快捷键：`Ctrl / ⌘ + Enter` 运行代码；`Tab` 缩进 4 空格。
- 卡住时可以用「💡 提示」和「查看答案」，看完答案记得理解再自己写一遍。
